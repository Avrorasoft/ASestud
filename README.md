# 🏫 Sistema de Gestión Escolar - Colegio Dr. Antonio Vaca Díez

## 🚀 Descripción del Proyecto
Sistema web moderno, responsive y multiusuario para la gestión integral del Colegio Dr. Antonio Vaca Díez. Esta aplicación es la evolución de un sistema de escritorio (Tkinter) y está diseñada para optimizar los procesos administrativos, académicos y financieros de la institución.

## 🛠️ Stack Tecnológico
- **Backend:** Python + Flask (Arquitectura modular con Blueprints)
- **Base de Datos:** MySQL / MariaDB (Flask-SQLAlchemy + PyMySQL)
- **Frontend:** HTML5, Jinja2, Bootstrap 5, Chart.js
- **Autenticación:** Flask-Login (Roles: Administrador, Secretaría, Profesor)

## 📦 Módulos del Sistema
1. Dashboard con métricas en tiempo real
2. Gestión de Inscripciones y Estudiantes (con fotos y gestión de padres)
3. Control de Profesores y Personal Administrativo
4. Módulo de Pagos, Caja y Generación de Facturas PDF
5. Registro y Reportes de Gastos
6. Libro de Calificaciones y Generación de Boletines PDF
7. Control de Faltas y Licencias
8. Mensajería WhatsApp (Integración vía wa.me)
9. Cardex Personal (Historial completo de personas)
